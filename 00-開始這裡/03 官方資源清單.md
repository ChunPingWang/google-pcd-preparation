# 03 官方資源清單

> [!tip] 原則
> **筆記建立骨架，官方文件補肉。** 遇到本 Vault 標 🔢 的數字或覺得可疑的細節，一律回官方文件查證。

## 🎯 考試本身

| 資源 | 連結 | 用法 |
|---|---|---|
| 認證頁（規格、費用） | https://cloud.google.com/learn/certification/cloud-developer | 報名前確認最新規格 |
| **官方考試指南 PDF** | https://services.google.com/fh/files/misc/professional_cloud_developer_exam_guide_english.pdf | ⭐ 每週回讀一次，當檢核清單 |

## 📖 必讀官方文件（依考試權重排序）

### Cloud Run（最重要）
- 總覽與開發指南：https://cloud.google.com/run/docs
- 服務 vs 工作（Jobs）：`/run/docs/resource-model`
- 修訂版本與流量分流：`/run/docs/managing/revisions`
- 觸發器與事件：`/run/docs/triggering`
- 配額與限制 🔢：`/run/quotas`

### GKE
- 概念總覽：https://cloud.google.com/kubernetes-engine/docs/concepts
- Autopilot 概觀與限制：`/kubernetes-engine/docs/concepts/autopilot-overview`
- HPA：`/kubernetes-engine/docs/concepts/horizontalpodautoscaler`
- Workload Identity Federation for GKE：`/kubernetes-engine/docs/concepts/workload-identity`
- Kubernetes 官方 probe 文件：https://kubernetes.io/docs/tasks/configure-pod-container/configure-liveness-readiness-startup-probes/

### 架構與最佳實務（讀了就會答對很多情境題）
- **Architecture Framework**：https://cloud.google.com/architecture/framework
- **Cloud Native / 12-Factor on Google Cloud**：https://cloud.google.com/architecture/twelve-factor-app-development-on-gcp
- **API 設計指南**：https://cloud.google.com/apis/design
- **SRE Book（SLO / error budget）**：https://sre.google/books/
- 資料庫選型：https://cloud.google.com/products/databases

### 整合與訊息
- Pub/Sub：https://cloud.google.com/pubsub/docs（重點：`subscriber`、`exactly-once`、`ordering`、`dead-letter`）
- Cloud Tasks：`/tasks/docs`（重點：與 Pub/Sub 的差異頁）
- Eventarc：`/eventarc/docs`
- Workflows：`/workflows/docs`

### 安全
- IAM 概觀與最佳實務：https://cloud.google.com/iam/docs/using-iam-securely
- ADC 驗證流程：https://cloud.google.com/docs/authentication
- Secret Manager：`/secret-manager/docs`
- Workload Identity Federation：`/iam/docs/workload-identity-federation`
- Binary Authorization：`/binary-authorization/docs`

### 可觀測性
- Google Cloud Observability：https://cloud.google.com/stackdriver/docs
- 結構化記錄：`/logging/docs/structured-logging`
- OpenTelemetry on Google Cloud：https://cloud.google.com/stackdriver/docs/instrumentation/setup

### Gen AI（2026 新增考點）
- Vertex AI 生成式 AI：https://cloud.google.com/vertex-ai/generative-ai/docs
- Gemini API 快速入門與 function calling
- Gemini Code Assist：https://cloud.google.com/products/gemini/code-assist

## 🧪 免費練習環境

| 資源 | 說明 |
|---|---|
| **Free Tier** https://cloud.google.com/free | 新帳號 $300 額度 90 天；Cloud Run / Cloud Build / Logging 都有永久免費額度 |
| **Cloud Shell** | 瀏覽器內就有 `gcloud`、`kubectl`、`docker`，不用裝東西 |
| **Qwiklabs / Cloud Skills Boost** | 有些 lab 免費，GKE / Cloud Run 的 lab 值得做 |
| **本地模擬器** | Firestore / Pub/Sub / Bigtable / Spanner 都有 emulator，見 [[開發環境 Cloud Code Shell Workstations 與 AI 工具]] |

> [!warning] 成本守則
> 練習時一定做這三件事，避免帳單意外：
> 1. 開一個**專用 project**，考完直接刪掉整個 project。
> 2. 設定 **Budget Alert**（$10 即可）：`Billing → Budgets & alerts`。
> 3. Lab 結束跑清理指令（每篇 Lab 末尾都有「🧹 清理」章節）。
