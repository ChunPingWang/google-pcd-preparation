## 🚀 Cloud Run（最高頻）

| 項目 | 值 |
|---|---|
| 請求逾時 **預設** | **5 分鐘**（300 秒） |
| 請求逾時 **上限** | **60 分鐘**（3600 秒） |
| 並行（concurrency）**預設** | **80** / 實例 |
| 並行 **上限** | **1000** / 實例 |
| 記憶體上限 | **32 GiB** |
| vCPU 上限 | **8** |
| 請求 / 回應大小（HTTP/1） | **32 MiB** |
| 容器啟動逾時 | **4 分鐘** |
| 實例連續執行上限 | 約 **7 天**後自動重啟 |
| 每服務 revision 上限 | 1000 |
| 預設最大實例數（每 region） | **100**（可申請提高） |
| 環境變數數量 / 單一大小 | 1000 / 32 KB |
| CPU 配置預設 | **僅請求期間**（cpu-throttling） |

## ☸️ GKE / Kubernetes

| 項目 | 值 |
|---|---|
| Probe `periodSeconds` 預設 | **10 秒** |
| Probe `timeoutSeconds` 預設 | **1 秒**（很短！） |
| Probe `failureThreshold` 預設 | **3** |
| Probe `initialDelaySeconds` 預設 | 0 |
| Liveness/Startup 的 `successThreshold` | 只能是 **1** |
| **最長容忍啟動時間** | `initialDelay + failureThreshold × periodSeconds` |
| HPA 評估週期 | 約 **15 秒** 🔢 |
| HPA `minReplicas` 最小值 | 1（可設 0 需特定功能） |
| 預設 `terminationGracePeriodSeconds` | **30 秒** |
| QoS 三級 | Guaranteed（requests==limits）/ Burstable / BestEffort |
| 記憶體超過 limit | **OOMKilled**（直接殺） |
| CPU 超過 limit | **被節流**（變慢，不殺） |
| Autopilot 是否預設開 Workload Identity | **是** |

## 📋 錯誤碼 → 行動（背這張就夠）

| 錯誤 | 重試？ | 行動 |
|---|---|---|
| 400 `INVALID_ARGUMENT` | ❌ | 修請求 |
| 401 `UNAUTHENTICATED` | ❌ | 檢查憑證 / token 型別 |
| 403 `PERMISSION_DENIED` | ❌ | **補 IAM 角色** |
| 403 `SERVICE_DISABLED` | ❌ | **啟用 API** |
| 404 `NOT_FOUND` | ❌ | — |
| 409 `ALREADY_EXISTS` | ❌ | 通常＝已處理（冪等成功） |
| 409 `ABORTED` | ✅ | 重試整個**交易** |
| 429 `RESOURCE_EXHAUSTED` | ✅ | **指數退避** + 降併發 + 提額 |
| 500 / 503 | ✅ | 指數退避 |
| 504 `DEADLINE_EXCEEDED` | ⚠️ | 退避重試（**必須冪等**） |

## 🧮 三個要會算的公式

```
① Cloud Run 實例數 ≈ 進行中的請求數 ÷ concurrency

② K8s probe 最長容忍時間 = initialDelaySeconds + failureThreshold × periodSeconds

③ 退避延遲 = min(base × 2^attempt, cap) + random(0, jitter)
```

**Error budget 換算**
| SLO | 30 天可失敗時間 |
|---|---|
| 99% | ~7.2 小時 |
| 99.9% | **~43 分鐘** |
| 99.99% | ~4.3 分鐘 |
| 99.999% | ~26 秒 |
