# 00 服務索引（全服務地圖）

> [!tip] 這篇的用途
> 1. **Graph View 的樞紐**：所有服務筆記都從這裡連出去，打開圖表視圖就能看到整體結構。
> 2. **考前掃描**：每個服務一句話定位，30 秒確認有沒有盲區。
>
> 🔁 **想看服務之間怎麼串起來**（請求怎麼流、誰依賴誰）→ 看 [[00 技術關聯地圖]]。
> 這篇是**分類清單**，那篇是**資料流與依賴**。

## 🖥 運算（Compute）

| 服務 | 一句話定位 | 筆記 |
|---|---|---|
| **Cloud Run** | 全代管容器服務，按請求擴充、可縮到 0 — **PCD 的主角** | [[Cloud Run]] |
| Cloud Run Jobs | 跑完就結束的批次工作（非 HTTP） | [[Cloud Run Jobs 與 Functions]] |
| Cloud Run functions | 事件驅動的單一函式（原 Cloud Functions） | [[Cloud Run Jobs 與 Functions]] |
| **GKE** | 代管 Kubernetes；Autopilot（代管節點）/ Standard（自管節點） | [[GKE 基礎與 Autopilot]] |
| GKE 工作負載 | Deployment / probe / HPA / requests-limits | [[GKE 工作負載 健康檢查與自動擴充]] |
| Compute Engine | IaaS 虛擬機，最大控制權、最高維運成本 | [[Compute Engine 與 App Engine]] |
| App Engine | 老牌 PaaS；新專案優先選 Cloud Run | [[Compute Engine 與 App Engine]] |

## 🗄 資料與儲存（Data）

| 服務 | 一句話定位 | 筆記 |
|---|---|---|
| **Cloud Storage** | 物件儲存；class / lifecycle / signed URL | [[Cloud Storage]] |
| **Cloud SQL** | 代管 MySQL / PostgreSQL / SQL Server | [[Cloud SQL 與 AlloyDB]] |
| **AlloyDB** | PostgreSQL 相容的高效能版本，含分析加速 | [[Cloud SQL 與 AlloyDB]] |
| **Firestore** | 無伺服器文件資料庫，即時監聽 + 離線同步 | [[Firestore]] |
| **Spanner** | 全球分散、強一致、水平擴展的關聯式資料庫 | [[Spanner]] |
| **Bigtable** | 超大規模寬列（wide-column）NoSQL，低延遲高吞吐 | [[Bigtable]] |
| **Memorystore** | 代管 Redis / Valkey / Memcached，亞毫秒快取 | [[Memorystore 與快取策略]] |
| **BigQuery** | 無伺服器資料倉儲，SQL 查 PB 級資料 | [[BigQuery 給開發者]] |

## 📨 整合與編排（Integration）

| 服務 | 一句話定位 | 筆記 |
|---|---|---|
| **Pub/Sub** | 全球訊息總線，一對多扇出、削峰、串流 | [[Pub Sub]] |
| **Cloud Tasks** | 對**單一目標**的非同步任務佇列，可控速率與排程 | [[Cloud Tasks]] |
| **Eventarc** | 事件路由：把 GCP 事件送到 Cloud Run / GKE / Workflows | [[Eventarc]] |
| **Workflows** | 無伺服器工作流編排，宣告式連接多個服務 | [[Workflows 與 Cloud Scheduler]] |
| **Cloud Scheduler** | 全代管 cron | [[Workflows 與 Cloud Scheduler]] |
| **API Gateway / Apigee** | API 前門：驗證、限流、版本、可觀測性 | [[API 管理 Apigee 與 API Gateway]] |

## 🔐 安全與身分（Security）

| 服務 | 一句話定位 | 筆記 |
|---|---|---|

| **Artifact Analysis / Binary Authorization** | 映像漏洞掃描 + 部署准入控制 | [[供應鏈安全 Artifact Analysis 與 Binary Authorization]] |
